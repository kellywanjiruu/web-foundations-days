About QuickNotes

QuickNotes is a simple web app for capturing short notes before they slip your mind. It is built to be fast, distraction-free and easy to use on any device.

How to use QuickNotes

  1. Open the Home page and find the "Add a note" form.
  2. Type your note into the text box.
  3. Click "Add Note" or press Enter to save it.
  4. Your note appears in the "Your notes" list below.

Features

  • Quick one-line note capture
  • Clean, distraction-free layout
  • Works on phones, tablets and desktops
  • Accessible with keyboard and screen readers

Keyboard shortcuts

Shortcut Action
Enter Add the note
Ctrl + S Save the file in VS Code
